# Zero SR/S Wire Harness

Wiring harness documentation traced from a Zero Motorcycles SR/S (Gen3 FST platform).

Each [harness page](harness/index.md) shows the wiring diagram and its bill of materials.
Diagrams are generated from the YAML sources in
[`harness/`](https://github.com/atomicdog/ZeroMotoWireharness/tree/master/harness)
with [WireViz](https://github.com/wireviz/WireViz).
